## 图标制作建议

### 风格要求
- 简洁清晰，符合整体设计风格
- 使用统一的配色方案
- TabBar 图标建议使用单色或渐变色
- 分类图标可以使用实物照片或插画

### 配色方案
主色调：#d4a574（金色）
辅助色：#5bc1de（蓝色）
背景色：#f8f8f8（浅灰）

### 工具推荐
- Figma - 在线设计工具
- Sketch - macOS 设计工具
- Adobe Illustrator - 矢量图形设计
- Canva - 在线设计平台（适合非设计师）
